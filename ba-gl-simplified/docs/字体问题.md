# 已知问题：部分字形的大小 / 粗细不一致

> **English summary**: after localisation, characters that actually changed
> (動→动, 務→务, 購→购) render slightly thinner/smaller than characters that are
> identical in both scripts (活, 石, 任). This is a real rendering issue caused by the
> GL Android build shipping only a trimmed CJK font subset. It **cannot be fixed
> without root or without modifying the client**; the tool mitigates it by setting the
> app language to Simplified Chinese.

---

## 现象

汉化后界面文本 100% 正确、功能完全正常，但：

- **被改动过的字**（動→动、務→务、購→购、覽→览、編→编）看起来**更细 / 更小**
- **繁简同形的字**（活、石、任、咖、啡、青）保持正常
- 同一行文字内混用两种字形观感

## 实测结论：8 种手段全部无效

在 Android 12 模拟器（有 root）与真机上逐一实测，**渲染结果均无变化**：

| # | 手段 | 结果 |
|---|---|---|
| 1 | 修改外部 bundle 中 TMP 字体资产的源字体引用 | ❌ |
| 2 | 给 bundle 中 0 字节的空壳 `Font` 资产填入字体数据 | ❌ |
| 3 | 移植其它区服（国服）的 TMP 字体资产 + 图集 + 源字体 | ❌ |
| 4 | 替换系统字体（含中日韩 4 款全部替换） | ❌ |
| 5 | 替换 APK 内置字体（4 款） | ❌ |
| 6 | 把 TMP 图集设为运行时可写 + 提供源字体 | ❌ |
| 7 | 替换 APK 内置**全部 12 款**字体（按 cmap 精确判断） | ❌ |
| 8 | 改写系统 `/system/etc/fonts.xml` fallback 链，强制全部指向同一款简体字体 | ❌ |

## 根因

**GL 安卓构建时裁剪了中文字体文件。**

APK 内 `assets/bin/Data/<GUID>`（Unity 序列化资产，`Font.m_FontData` 即字体文件）：

| 字体 | cmap 字符数 | 缺简体独有字形 |
|---|---|---|
| `NotoSansTC-Medium` | 20,748 | ✗ 缺 厅 览 编 购 辉 办 |
| `NotoSansTC-Bold` | 20,748 | ✗ 同上 |
| `MALGUN`（韩） | 27,133 | ✗ 同上 |
| `MainFont` / `MainFont_Bold` | 12,294 / 12,293 | 韩文标题字体，几无中文 |

且该 TMP 字体资产的**源字体引用为空**：

```
TMP 资产 'U-OTF-ShinMGoUpr-DeBold SDF'
    m_AtlasPopulationMode = 1（动态）
    m_SourceFontFile      = { m_FileID: 0, m_PathID: 0 }   ← 空
    m_SourceFontFileGUID  = 'bac7aba6…'                    ← 该 GUID 对应的字体文件在本客户端不存在
    m_GlyphTable          = 13,235 个字形（烘焙自原繁体文本）
    m_AtlasTextures[0].m_IsReadable = False                 ← 运行时不可写
```

→ 动态模式形同虚设：**图集里没有的字形无法现场生成，只能逐字回退**到另一款字体
→ 改动过的字与未改动的字来自不同字体 → 字形大小/粗细不一致

对比其它区服客户端：它们**保留了** `U-OTF-ShinMGoUpr-*.otf` 字体文件，
因此替换字体即可生效；GL 安卓端把该文件整个裁掉了，所以无法照搬。

## 结论

> **在不 root、不修改客户端（APK / 引擎代码）的前提下，本问题无法根治。**

原因：目标 UI 的字体来自客户端内置资源，外部（下载目录 / bundle / 系统字体）**没有覆盖入口**。

## 目前的缓解措施

`localize_phone.ps1` / `localize_phone.sh` 在 Android 13+ 上会自动执行：

```bash
adb shell cmd locale set-app-locales com.nexon.bluearchive --locales zh-Hans-CN
```

把 App 语言设为简体中文，可**减轻**（不根治）观感差异。
彻底解决需要 root 更换系统字体，或修改客户端内置字体（两者都超出本工具范围）。

## 参考

- [BlueArchive-Translation/BA-APKSRC](https://github.com/BlueArchive-Translation/BA-APKSRC)
  —— 其它区服的 APK 资源（含已适配简体的 `U-OTF-ShinMGoUpr-*.otf`）。
  ⚠️ 其做法需要重新打包并重签名 APK，**与本工具"无需 root、无需重签"的定位不同**，
  且修改客户端存在账号风险，**不建议普通用户尝试**。

## 附带确认（对排查有用的事实）

- **替换下载目录中的 bundle，客户端不会校验、不会重新下载**（SHA-256 保持推入值）
  → 不需要处理 Addressables catalog
- bundle 是**压缩**的，`grep` 无法搜索内部字符串 → 扫描需用 UnityPy 逐个加载
- `UnityPy==1.25.4` 依赖 `tpk_ar`（仅 sdist，需 Rust 编译）→ 建议使用 `1.25.2`

## 免责

本问题**不影响任何功能**：文本内容 100% 正确，仅字形观感存在差异。
